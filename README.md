# 📚 Knowledge Base Management UI

A premium, responsive, and pixel-accurate dashboard for managing internal knowledge bases, built with **React**, **Vite**, and **Tailwind CSS**.

## 🚀 Live Preview

[**View Live App on Vercel**](https://aventisia-junior-developer-ochugfvr5.vercel.app)

---

## ✨ Features

- **Responsive Dashboard**: Sidebar and header layout optimized for all screen sizes.
- **Knowledge Base Grid**: Clean, card-based UI for browsing existing knowledge bases.
- **Interactive "Create New" Flow**: Fully styled modal for adding new knowledge bases.
- **Modern Tech Stack**: Uses Tailwind CSS v4 and Lucide React for a sleek, performant experience.
- **Glassmorphism & Micro-animations**: Subtle hover effects and transitions for a premium feel.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

```bash
src/

│   └── MainLayout.jsx       # Layout wrapper (Sidebar + Header)

```

## 🏃 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository or navigate to the directory:
   ```bash
   cd "Aventisia Junior Developer"
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
